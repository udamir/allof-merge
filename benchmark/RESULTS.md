## Correctness

Every case of the fuzz corpus (`test/fuzz/corpus`: real-world cases collected from the test suites and issue trackers of these and other libraries, probes, allof-merge fuzz regressions) without allof-merge-specific options. A result is **equivalent** when it gives every generated instance the same verdict as the input (@cfworker/json-schema, the oracle of the test suite), **allOf-free** when it is equivalent and holds no `allOf`; a **mismatch** accepts (lax) or rejects (strict) an instance the input does not. Cases whose input the oracle cannot load are skipped. The corpus was used to develop allof-merge 1.0, so read its numbers as a regression check rather than an unbiased comparison; the `real-world` rows are the fairest.

## Caveats

- The oracle compares verdicts on generated instances (boundary values, enum members, pattern samples, property names of the schemas); a difference no generated instance exposes is not seen. Example: for `allOf: [{ properties: { foo, foo123 }, patternProperties: { "^bar": {} }, additionalProperties: false }, { properties: { bar, bar123 }, patternProperties: { ".+\\d+$": {} }, additionalProperties: false }]` json-schema-merge-allof returns `{ additionalProperties: false, properties: { foo123, bar, bar123 } }`, which rejects `barX9` (allowed by both items); it counts as equivalent here. allof-merge keeps the two shapes and reports `object-shape-kept`.
- `throws` includes libraries reporting a contradiction by throwing (json-schema-merge-allof, @x0k/json-schema-merge, @fastify/merge-json-schemas throw on incompatible `type`s); allof-merge writes `false` and reports an `unsatisfiable` issue instead.
- Libraries that do not resolve `$ref` are run on the `$ref` cases as they are (no dereferencing): a `$ref` inside `allOf` stays a part, which is equivalent but not allOf-free.
- allof-merge's non-equivalent results are its decided format rule: two different `format`s make the schema `false`, which rejects non-string instances the input accepts.
- Each library runs the corpus in a child process with a 10 s per-case timeout; speed is measured in one process, one library after the other, with a fresh copy of the input per run.
